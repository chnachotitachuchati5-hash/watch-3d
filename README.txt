นาฬิกากลไกหรู — เว็บ 3D แยกชิ้นส่วน
===================================

เปิดไฟล์ index.html ใน Chrome / Edge / Firefox (แนะนำผ่านเซิร์ฟเวอร์เล็ก ๆ)

  python3 -m http.server 8765 --directory .

แล้วเปิด http://127.0.0.1:8765/

ถ้าไม่มีเน็ต ให้เติม ?offline=1 หรือปล่อยให้หน้าเว็บสลับไปใช้ไฟล์ใน vendor/ เอง
เมื่อ CDN โหลดไม่สำเร็จ

วิธีเล่น
- เลื่อนลูกกลิ้งหรือลากสไลเดอร์ เพื่อแยก / ประกอบชิ้นส่วน
- ปุ่ม: แยกชิ้นส่วน, ประกอบกลับ, โหมด X-ray, หมุนอัตโนมัติ
- คลิกหรือชี้ที่ชิ้นส่วน เพื่อดูชื่อและเกร็ดฟิสิกส์ภาษาไทย
- ลากเมาส์เพื่อหมุนกล้อง (OrbitControls)
